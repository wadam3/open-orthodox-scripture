# Separate exploratory option: 100% self-hosted production

This document is intentionally **not** a requirement for the main project. It covers the user's separate interest in a no-cloud production stack run on hardware they control.

Possible components to evaluate: local Git hosting (Forgejo), local task management, source-text database, offline Greek/English language tooling, local text-to-speech models, audio mastering and QC, local object storage/backups, and self-hosted distribution.

A future feasibility study should identify software licenses, model-weight licenses, hardware/energy costs, audio quality, storage, operational overhead, backup strategy, and technical limits. Avoid presenting local inference as a guarantee of ecclesiastical accuracy. No vendor or model is selected here.

The current GitHub collaboration repository is part of the primary plan. A fully self-hosted alternative could mirror it to a local forge or become the canonical host if later chosen.
