# Roadmap — Genesis and Septuagint first

All milestones are for an **independent**, not officially Church-approved project. See \`docs/TRANSLATION_PROTOCOL.md\` for detailed stages.

## Phase 0 — Mission, rights, and workflow

- [x] Agree mission: make Holy Scripture and Orthodox Christian literature freely accessible.
- [x] Adopt working independent-project disclaimer (no Church/jurisdiction/diocese approval implied).
- [x] Select Genesis 1 as the **first drafting pilot**, Old Testament before New Testament.
- [x] Set founding sequence: **no external collaborators until the entire provisional Bible translation has been drafted**.
- [x] Document intended free + paid print, ebook, YouTube, optional Spotify, and Audible distribution.
- [ ] Finalize content/code license and contributor attribution, including commercial reuse and source exclusions.
- [ ] Verify and approve a precise Greek Septuagint source edition for Genesis and its rights.
- [x] Approve a working 49-main-OT-plus-4-Maccabees-appendix / 27-NT translation production order, with documented ancient alternatives: [approved order](BOOK_ORDER_AND_WORKFLOW.md), [historical comparison](ANCIENT_BOOK_ORDER_COMPARISON.md).
- [ ] Resolve subsidiary content mapping decisions: Prayer of Manasseh/Odes, Esdras–Ezra/Nehemiah, Greek Esther/Daniel additions, and Greek Daniel text form.
- [ ] Decide English register, names, translation/variant conventions, glossary, and style guide.

## Phase 1 — Establish and validate Genesis 1 draft protocol

- [ ] Record exact rights-reviewed LXX Genesis source reference and chapter/verse mapping.
- [ ] Define prompt/review rubrics and required provenance/variant fields.
- [ ] Draft original English Genesis 1 with AI assistance; log input source, variants, uncertainties, and all substantive decisions.
- [ ] Perform a separate Greek-to-English internal audit and revise.
- [ ] Validate structured chapter; mark **provisional**, not approved.
- [ ] Revise protocol after this pilot.

## Phase 2 — Complete entire provisional Orthodox Bible draft

- [ ] Finish all Genesis chapters in numeric order, then each subsequent book from start to finish in [the approved 77-target sequence](BOOK_ORDER_AND_WORKFLOW.md), requiring provisional-book completion before moving on; complete the Old Testament appendix before the New Testament.
- [ ] Rights-check and choose a Greek New Testament edition.
- [ ] Draft the complete New Testament.
- [ ] Audit consistency, unresolved items, and completeness across the entire planned canon.
- [ ] Freeze/tag a reproducible **complete provisional draft** with no claim of qualified human review or Church approval.

## Phase 3 — External collaborators and approval

**Begin only after Phase 2.**

- [ ] Recruit technical maintainers and qualified Greek/English editors and Orthodox theological reviewers.
- [ ] Confirm qualifications and permission to attribute contributors.
- [ ] Independently review source fidelity, theology/liturgical terms, unresolved variants, and usability.
- [ ] Obtain documented rights, Greek/English language, Orthodox, and release editorial sign-offs.
- [ ] Release appropriately reviewed and versioned text without implying ecclesiastical authorization.

## Phase 4 — Print, ebook, and audio editions

- [ ] Free reviewed source text and accessible ebooks.
- [ ] Print: individual biblical books, Old/New Testaments, and possible complete Bible (including multi-volume alternatives).
- [ ] Free YouTube narration of each individual book, linked to approved text releases.
- [ ] Investigate free Spotify listening subject to eligibility and rights.
- [ ] Paid Audible individual books, Testament collections, and possible whole Bible, subject to platform limits and applicable nonexclusive terms.
- [ ] Default to the same approved narration across platforms unless a premium edition provides a substantial difference.
- [ ] Publish credits, version/corrections process, and independent-Church-status disclaimer everywhere appropriate.

The separate [100% self-hosted alternative](SELF_HOSTED_OPTION.md) remains an exploratory side plan, not a requirement of the main project. The public GitHub collaboration space remains the primary repo until changed.
