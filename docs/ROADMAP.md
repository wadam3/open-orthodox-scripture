# Roadmap

## Phase 0 - Establish the project

- [ ] Confirm public name and repository description
- [ ] Approve text/audio and software licensing
- [ ] Publish steward and maintainer contact information
- [ ] Recruit initial technical maintainers and language/editorial reviewers
- [ ] Define Orthodox-relevant review credentials and appeal path
- [ ] Select and rights-check an appropriate Greek NT source edition

## Phase 1 - Mark 1 pilot

- [ ] Document Mark 1 text-critical and translation conventions
- [ ] Translate verses with citations to source edition and notes
- [ ] Perform Greek-language and English editorial review
- [ ] Obtain named Orthodox theological review
- [ ] Publish reviewed pilot as text with full version metadata

## Phase 2 - Audiobook pilot

- [ ] Decide human narration / consented synthetic voice / both
- [ ] Establish glossary and pronunciation review
- [ ] Produce chapter audio from approved text
- [ ] Test listener experience, accessibility, and provenance metadata
- [ ] Publish reproducible audio pilot with attribution

## Phase 3 - New Testament and beyond

- [ ] Expand by book with the same review gates
- [ ] Plan a Septuagint-oriented Old Testament, including source rights and book-order decisions
- [ ] Build release packaging, accessibility formats, and contributor onboarding

A separate [100% self-hosted alternative](SELF_HOSTED_OPTION.md) is research, not a requirement of the primary plan.
