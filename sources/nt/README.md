# New Testament source workspace — reserved

This directory reserves a place for future **independently verified public-domain Greek New Testament source text**.

No base edition has been selected, rights-cleared for import, or transcribed. Selection follows the provisional Old Testament drafting sequence established in [the translation protocol](../../docs/TRANSLATION_PROTOCOL.md). When that stage begins, record the exact historical edition, manuscript basis, provenance, rights determination, and transcription validation in [the source register](../../docs/SOURCE_REGISTER.csv).

Do not import modern copyrighted scholarly editions or electronic datasets requiring third-party permission or a negotiated license.
