# Old Testament source workspace

The Old Testament source tradition is the Greek Septuagint. The proposed translation inventory has **49 main Old Testament book workspaces plus Fourth Maccabees as an appendix**; see [the translation index](../../translation/ot/README.md). The source-text collection must be mapped to those book workspaces because historical Greek editions sometimes combine or divide books differently.

## Intake order

1. Begin with **Genesis 1**. Fix the exact historical printed Greek source and the scan/page/verse correspondence.
2. Prepare an **original, page-verified** Greek transcription, without borrowing modern electronic editions whose rights are unverified.
3. Review Greek variants, numbering, and Orthodox textual usage using independently usable evidence. Keep analysis in the separate Genesis research log and any necessary explanations in the translation footnotes.
4. Expand book by book, maintaining a mapping from each source's printed divisions to this project's canonical book IDs.

Differences requiring special attention later include alternative divisions of Esdras/Ezra-Nehemiah, Psalms and its additions, the Prayer of Manasseh, Greek Esther, Greek Daniel, and Fourth Maccabees' appendix status. This is an **intake plan**, not a claim that every passage or source witness has been authenticated.
