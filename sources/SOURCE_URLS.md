# Historical source URLs — reference-only index

**Recorded: 2026-11-12.** This page collects the verified **catalog and historical scan URLs** we have identified so we can find them later. **No files have been downloaded, transcribed, or imported into this GitHub repository by creating this index.** Listing a URL is not an approval for copying a site's modern editorial additions, OCR, proprietary ebook format, or third-party transcription.

**Historical background:** [Swete source history and manuscript cautions](../docs/SWETE_SOURCE_BACKGROUND.md). For Genesis 1, the surviving manuscript of **Codex Vaticanus** lacks the opening of Genesis; Swete's edition includes it using other witnesses. The manuscript source of individual verses must be verified from the historic print rather than guessed.

## Historical book order reference (not a Greek text source)

- **Swete, *An Introduction to the Old Testament in Greek* (1900), Part II, chapter I** — [historical chapter on book titles, groups and sequence](https://www.ccel.org/ccel/swete/greekot.iv.i.html). Used as a bibliographic reference for ancient codex book orders; not the base Greek source for translating Genesis. See [ancient book order comparison](../docs/ANCIENT_BOOK_ORDER_COMPARISON.md).

## Sources intentionally not added as reusable text

Rahlfs–Hanhart, Göttingen and modern Church of Greece Greek printings are described in [Greek source edition comparison](../docs/SEPTUAGINT_SOURCE_COMPARISON.md), but **have no verified independently reusable public-domain status for our intended text import**. They are **reference-only or excluded for copying**, not part of a download queue. The project's New Testament and Apostolic Fathers source editions are not selected or approved for copying.

## Next step when source copies are needed

Locate the precise historical scan, check its title page and printed pages, record rights/provenance and any restrictions, and prepare an independently verified Greek transcription. Record every actual imported source in [the source register](../docs/SOURCE_REGISTER.csv), with evidence and status. **The link index alone does not satisfy a source-import approval or translate any chapter.** No permission or licensing requests will be made.
