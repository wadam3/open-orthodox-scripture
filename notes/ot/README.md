# Old Testament — per-book notes

Each proposed Old Testament book, including the 4 Maccabees appendix, has a separate research-and-decisions README in its own directory. Notes do not form part of the final Scripture text.

All entries are initially empty placeholders. Add source and variant references, translation choices, AI cross-checks and corrections, and unresolved questions here—not in the clean verse text.

Use the [Old Testament book index](../../translation/ot/README.md) to navigate translation files and their paired notes.

No chapter is approved and no official Church endorsement is claimed.
