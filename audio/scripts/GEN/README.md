# Genesis 1 — unreleased working narration script

This folder contains a **text-only pilot**, not an approved narrated audiobook. The input is the current [31-verse JSON draft](../../../translation/ot/GEN/001.json). The [clean narration text](001.narration.txt) is **mechanically derived** from those verse strings: “Genesis. Chapter one.” is the only extra spoken title, and verse boundaries 5/8/13/19/23/31 create natural paragraph pauses. No words within any verse are altered. Verse numbering remains available in JSON for navigation and accessibility but is not read by default.

The main script excludes manuscript footnotes and URL citations for smooth listening; an accessible explanatory notes track/transcript must accompany any future release. See [the Genesis 1 source audit](../../../notes/ot/GEN/001.source-audit.md) for the first-edition 1887 pages, historical Brenton comparison, bracket and manuscript notes, two recent English revisions, and outstanding reviews.

**Status:** Provisional text only; source transcription, independent Greek fidelity audit, audiobook voice/rights/production, and formal Orthodox/language/editorial approvals incomplete. The revised phrases at Genesis 1:20 and 1:31 have not been separately auditioned since their changes. Do not call this publication-ready.
