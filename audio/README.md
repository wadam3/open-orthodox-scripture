# Audio workspace

No audiobook recordings are included yet. Audio must be linked to an approved translation commit and accompanied by source/version, voice-rights, narration disclosure, quality-control, and attribution metadata. See `docs/AUDIO_PLAN.md`.

Do not commit large audio model weights, personal voice samples without written permission, or third-party copyrighted recordings.
